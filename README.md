# 🎮 Estudos PHP - E-commerce de Jogos

Projeto desenvolvido com foco em estudos de **PHP**, simulando um **e-commerce de jogos**, utilizando integração com banco de dados MySQL através do XAMPP.

O objetivo deste projeto é praticar conceitos fundamentais de desenvolvimento web back-end, organização de páginas dinâmicas e manipulação de banco de dados em PHP puro.

---

# 🚀 Tecnologias Utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP
- phpMyAdmin

---

# 📚 Objetivos do Projeto

Este projeto foi criado para praticar:

- Conexão com banco de dados MySQL
- CRUD com PHP
- Estruturação de páginas dinâmicas
- Organização de um sistema web
- Manipulação de formulários
- Sessões e autenticação
- Desenvolvimento de um sistema inspirado em e-commerce

# 🖥️ Funcionalidades

- Cadastro de jogos
- Listagem de produtos
- Sistema de navegação entre páginas
- Integração com banco de dados
- Estrutura de loja virtual
- Organização de conteúdo para estudos de back-end

# ⚙️ Como Executar o Projeto

## 1️⃣ Clone o repositório

```bash
git clone https://github.com/william-p-silva/Estudos-PHP.git
```

---

## 2️⃣ Mova a pasta para o diretório do XAMPP

Coloque o projeto dentro da pasta:

```bash
xampp/htdocs/
```

Exemplo:

```bash
C:/xampp/htdocs/Estudos-PHP
```

---

## 3️⃣ Inicie o XAMPP

Abra o painel do XAMPP e inicie:

- Apache
- MySQL

---

## 4️⃣ Configure o banco de dados

Abra o phpMyAdmin:

```bash
http://localhost/phpmyadmin
```

Depois:

1. Crie um banco de dados
2. Clique em **Importar**
3. Selecione o arquivo `.sql` do projeto
4. Clique em **Executar**

---

## 5️⃣ Execute o projeto

Abra no navegador:

```bash
http://localhost/Estudos-PHP
```
